# turf-tools-infra-example

This repo provides example infrastructure-as-a-service code for provisioning and deploying a single machine for [Turf Tools](https://github.com/turf-tools/turf-tools). It contains a [Pulumi](https://www.pulumi.com/) program that creates a bare-metal server on [Latitude.sh](https://www.latitude.sh/), and a script that deploys the app to it.

This repo is intended as a reference, not a supported tool. It shows what a working setup looks like, for people (and agents) setting up their own. You'll likely need to adapt it to your own needs: another provider, another way of creating the machine, a different topology (like Kubernetes), or a different stack (Ansible or Terraform). 

The guide in the core repo, [deploy/README.md](https://github.com/turf-tools/turf-tools/blob/main/deploy/README.md), is the source of truth for running Turf Tools: what it needs, how to configure it, setting up the database, and updating. This repo covers the part before that guide begins (creating the machine) and scripts one of its key steps.

## What's here

- `__main__.py`: the Pulumi program. It sets up one Latitude server running Ubuntu, with an SSH key, a firewall open to SSH, HTTP, and HTTPS, and a first-boot script that installs Docker.
- `Pulumi.example.yaml`: the settings a stack needs.
- `sdks/latitudesh/`: the Latitude provider's Python SDK, generated by `pulumi package add terraform-provider latitudesh/latitudesh` and committed so a fresh clone works without that step. Never hand-edited.
- `deploy.sh`: copies the app's deployment files and your configuration to the machine and starts the app (steps 3 and 4 of the app's guide).

## Create the machine

You need the [Pulumi CLI](https://www.pulumi.com/docs/iac/download-install/), [uv](https://docs.astral.sh/uv/), a Latitude account with an API token and a project (created in their dashboard), and an SSH key pair.

```bash
export LATITUDESH_AUTH_TOKEN=<your token>
pulumi stack init <stack>
cp Pulumi.example.yaml Pulumi.<stack>.yaml   # then fill it in
pulumi up
```

When `pulumi up` finishes, it prints the server's IP address. Before deploying, create a DNS record (an A record) pointing your domain at that address. The app requests an HTTPS certificate for your domain the first time it starts, and that only works once the domain leads to this machine.

## Deploy the app

With a checkout of the main repo beside this one, and your configuration written from its `deploy/.env.example`:

```bash
./deploy.sh <your domain or IP> my.env ../turf-tools
```

Re-run it to apply a changed configuration or new images. Then continue with step 5 of the app's guide, setting up the database.
